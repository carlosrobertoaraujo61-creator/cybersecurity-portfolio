# Fundamentos de Redes

## Objetivo

Registrar conceitos básicos de redes para estudo e revisão.

## Conceitos

- IP
- Máscara de rede
- Gateway
- DNS
- NAT
- DHCP

## Exemplo

```bash
ping 8.8.8.8
ip addr
traceroute google.com
```

## Observações

- Redes são compostas por dispositivos interconectados.
- O endereço IP identifica um host.
- O gateway permite comunicação com redes externas.

## Conclusão

O entendimento de redes é essencial para diagnosticar falhas e realizar segurança em ambientes digitais.
