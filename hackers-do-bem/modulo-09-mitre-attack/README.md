# Módulo 09 - MITRE ATT&CK

## Objetivo

Estudar a matriz MITRE ATT&CK e compreender táticas, técnicas e procedimentos usados por adversários.

## Conteúdo principal

- Táticas de ataque
- Técnicas e procedimentos
- Defender contra ataques conhecidos
- Modelo de adversário

## Anotações

- MITRE ATT&CK serve como referência para análise de ameaças e defesa.
- Ajuda a mapear ações que atacantes podem executar.
- É útil tanto para segurança ofensiva quanto defensiva.

## Conclusão

Ao entender como atacantes operam, é possível criar defesas mais eficazes e reduzir riscos estratégicos.
