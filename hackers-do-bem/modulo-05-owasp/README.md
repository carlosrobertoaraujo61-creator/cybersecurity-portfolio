# Módulo 05 - OWASP

## Objetivo

Aprender os riscos e vulnerabilidades mais comuns em aplicações web, conforme a OWASP.

## Conteúdo principal

- OWASP Top 10
- Injeção
- Broken Access Control
- XSS
- CSRF
- Configurações inseguras

## Anotações

- Aplicações web estão constantemente expostas a ataques.
- Segurança deve ser considerada desde o desenvolvimento.
- Testes de segurança ajudam a reduzir falhas críticas.

## Conclusão

A OWASP é indispensável para qualquer pessoa que trabalhe com desenvolvimento, pentest ou segurança de aplicações.
