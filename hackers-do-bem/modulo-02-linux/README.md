# Módulo 02 - Linux

## Objetivo

Aprender os conceitos básicos do sistema operacional Linux e sua utilização em ambientes de segurança.

## Conteúdo principal

- Estrutura de diretórios
- Comandos básicos
- Permissões
- Usuários e grupos
- Logs e manutenção

## Comandos essenciais

```bash
ls -la
pwd
whoami
id
sudo
chmod
chown
ps aux
netstat -tuln
```

## Anotações

- Linux é muito usado em servidores, pentest e ambientes de segurança.
- Entender permissões é fundamental para operar com segurança.
- O conhecimento de linha de comando acelera diagnósticos e automações.

## Conclusão

O Linux é uma ferramenta essencial para quem deseja atuar em segurança cibernética, redes e análise de sistemas.
