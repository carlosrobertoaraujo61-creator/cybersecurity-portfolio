# Módulo 03 - Redes

## Objetivo

Compreender os fundamentos de redes de computadores, topologias, protocolos e comunicação entre dispositivos.

## Conteúdo principal

- Modelo OSI e TCP/IP
- IP, máscara e gateway
- DNS
- HTTP/HTTPS
- Comandos de rede

## Conceitos importantes

- IP identifica um dispositivo na rede.
- DNS converte nomes em endereços IP.
- O modelo OSI ajuda a entender a comunicação em camadas.

## Ferramentas

- ping
- ipconfig / ifconfig
- traceroute
- nslookup
- tcpdump

## Conclusão

Redes são a base da comunicação digital e o entendimento de protocolos é essencial para análise e segurança computacional.
