# Laboratórios de Linux

## Objetivo

Registrar comandos, observações e exercícios realizados em ambientes Linux para reforço prático.

## Comandos básicos

```bash
ls -la
pwd
whoami
id
uname -a
cat /etc/passwd
```

## Observações

- Linux possui estrutura de diretórios organizada e padronizada.
- Permissões e usuários são fundamentais para garantir segurança.
- A linha de comando é a base para administração e investigação.
